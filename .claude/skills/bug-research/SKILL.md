---
name: bug-research
description: Investiga a causa raiz de um defeito antes de qualquer alteração.
---
1. Reproduzir (menor caso). 2. Localizar (stack trace, git blame, testes). 3. Hipótese em uma frase.
4. Confirmar com um teste que falha. 5. Corrigir com a menor mudança. 6. Deixar o teste de regressão.
Não altere código antes do passo 4.
